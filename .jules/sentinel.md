## 2026-08-11 - Profile Update Sanitization and Validation
**Vulnerability:** A Stored XSS and input validation/uniqueness bypass in user profile updates. While registration strictly sanitized the username and phone number, the profile update serializer (`UserProfileSerializer`) did not define corresponding field-level validation or sanitization, allowing attackers to inject malicious HTML scripts as usernames (displayable on leaderboards/chats) and bypass unique constraints causing unhandled IntegrityErrors.
**Learning:** Security validation must be applied across all endpoints modifying user model attributes, not just registration. Duplicate bypasses on phone numbers can occur if validation parses uncleaned raw input instead of formatted digits.
**Prevention:** Always validate and sanitize user profile inputs (`UserProfileSerializer`) with the same strictness and utilities used in registration, excluding the current instance from uniqueness queries to allow safe updates.
